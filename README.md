# Olist E-commerce Growth & Business Analytics

A SQL + Python analytics project based on the
Brazilian E-Commerce Public Dataset by Olist.

## Project Goal

This project simulates the work of a data analyst
supporting an e-commerce platform.

The analysis focuses on:

- Revenue and order performance
- Customer behavior and repurchase
- Customer retention
- RFM segmentation
- Product and seller performance
- Delivery performance
- Customer satisfaction

## Tech Stack

- PostgreSQL
- SQL
- Python
- Pandas
- NumPy
- Matplotlib
- Git / GitHub
